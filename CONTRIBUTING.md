# Kontribusi

Terima kasih ingin membantu menyempurnakan panduan ini.

## Cara berkontribusi
1. Fork repo ini.
2. Buat branch fitur: `git checkout -b perbaikan-modul-05`
3. Edit / tambah materi (utamakan Bahasa Indonesia, perintah harus valid di RHEL 9/10).
4. Pastikan struktur folder tetap: `modul/`, `lab/`, `referensi/`.
5. Commit dan buat Pull Request.

## Standar penulisan
- Tiap modul = satu file `.md` di folder `modul/` dengan nomor urut.
- Sertakan contoh perintah nyata (`bash`) dan penjelasan singkat.
- Tambahkan 1–2 latihan di akhir tiap modul (jawaban boleh di `lab/LAB.md`).
- Hindari informasi yang sudah usang (mis. `yum` tradisional — gunakan `dnf`).

## Menambah transkrip
Jika kamu punya transkrip video dari playlist, simpan di `transkrip/` lalu
sebutkan nomor video agar bisa dipetakan ke modul terkait.
